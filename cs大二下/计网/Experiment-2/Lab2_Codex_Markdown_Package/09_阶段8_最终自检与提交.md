# 阶段 8：最终自检、导出 PDF 与提交

> 目标：对实验报告、抓包文件、截图、字段表进行最终核验，生成最终 PDF，并按命名规范准备提交。  
> 输入：`report/draft.md`、截图、CSV、分析摘要。  
> 输出：最终 PDF、提交前检查清单。

---

## 1. 最终文件命名规范

最终报告文件名：

```text
计网实验2报告-班级（写3位班级号）-学号-姓名.pdf
```

示例：

```text
计网实验2报告-001-2026210000-张三.pdf
```

不要在最终文件名中保留：

```text
班级
学号
姓名
待填写
draft
final_final
```

---

## 2. 最终自检清单

### 2.1 报告结构检查

```text
[ ] 标准实验报告封面
[ ] 实验内容和实验目的
[ ] 实验环境
[ ] 实验工具
[ ] DHCP 捕获与分析
[ ] ICMP 捕获与分析
[ ] IP 数据报分片分析
[ ] TCP 建立连接与释放连接分析
[ ] 实验过程中遇到的问题和解决方法
[ ] 实验总结和心得体会
[ ] 附录或截图/抓包文件说明
```

### 2.2 DHCP 检查

```text
[ ] 写明捕获过滤器 udp port 67
[ ] 写明显示过滤器 dhcp 或 bootp
[ ] 写明 ipconfig /release 和 ipconfig /renew
[ ] 至少分析 Discover、Offer、Request、ACK
[ ] 如果有 Release，也已分析
[ ] 字段表包含 Frame Number
[ ] 说明 DHCP 地址分配过程
```

### 2.3 ICMP 检查

```text
[ ] 写明 ping 命令
[ ] 写明显示过滤器 icmp
[ ] 分析 Echo Request
[ ] 分析 Echo Reply
[ ] 说明 Type、Code、Checksum、Identifier、Sequence Number
[ ] 字段表包含 Frame Number
```

### 2.4 IP 分片检查

```text
[ ] 写明 ping -4 -n 1 -l 8000 目标
[ ] 写明分片显示过滤器
[ ] 字段表包含所有分片
[ ] 字段表包含 Total Length
[ ] 字段表包含 Identification
[ ] 字段表包含 DF
[ ] 字段表包含 MF
[ ] 字段表包含 Fragment Offset
[ ] 说明最后一个分片如何判断
[ ] 说明分片重组原理
```

### 2.5 TCP 检查

```text
[ ] 写明 tcp port 80 捕获过滤器
[ ] 写明 tcp.port == 80 或 tcp.stream == n 显示过滤器
[ ] 写明 curl 或打开网页的触发方式
[ ] 三次握手表包含 SYN、SYN+ACK、ACK
[ ] 连接释放表包含 FIN/ACK 或说明实际异常
[ ] 表中包含 Seq 和 Ack
[ ] 表中包含 Frame Number
[ ] 有 TCP 消息序列图
```

### 2.6 数据真实性检查

```text
[ ] 报告中的每个字段值可在 CSV 或截图中找到
[ ] 没有示例值残留
[ ] 没有 “x、y、...” 这类未替换占位符
[ ] 没有 “实际值” 这类占位符
[ ] 没有 “待填写” 残留，除非确实等待用户提供个人信息
```

---

## 3. 自动检查建议

让 Codex 搜索报告中的占位符：

```bat
findstr /n /i "待填写 TODO 实际值 示例 x+1 y+1 frame seq ack" report\draft.md
```

注意：`seq` 和 `ack` 是正常术语，Codex 需要人工判断是否是占位符残留。

---

## 4. Markdown 转 DOCX

如果安装了 Pandoc：

```bat
pandoc report\draft.md -o report\计网实验2报告-班级-学号-姓名.docx
```

将命令中的班级、学号、姓名替换成真实值。

---

## 5. DOCX 转 PDF

推荐方式：

1. 用 Word 或 WPS 打开 DOCX。
2. 检查图片、表格、分页。
3. 导出为 PDF。
4. 文件名使用规范格式。

如使用 Pandoc 直接导出 PDF：

```bat
pandoc report\draft.md -o report\计网实验2报告-班级-学号-姓名.pdf
```

如果缺少 LaTeX 环境导致失败，改用 Word/WPS 导出。

## 6. 最终提交材料建议保留

虽然平台通常只要求 PDF，但建议本地保留：

```text
report/计网实验2报告-班级-学号-姓名.pdf
captures/dhcp.pcapng
captures/icmp.pcapng
captures/ip_fragment.pcapng
captures/tcp.pcapng

screenshots/
```

---

## 7. 提交前人工复核重点

1. PDF 是否能打开。
2. 图片是否清晰。
3. 表格是否溢出页面。
4. TCP 序列图是否显示完整。
5. 文件名是否完全符合要求。
6. 班级是否为 3 位。
7. 学号和姓名是否正确。
8. 报告是否没有 Codex 提示语残留。
9. 报告是否没有 Markdown 代码块错误。
10. 是否没有“我作为 AI”等不合适表述。

---

## 8. 给 Codex 的提示语

```text
请执行阶段 8：最终自检、导出 PDF 与提交准备。

任务：
1. 检查 report/draft.md 是否存在。
2. 检查报告中是否存在 TODO、待填写、实际值、示例值、未替换 Mermaid 占位符。
3. 检查报告结构是否包含实验要求的所有章节。
4. 检查 DHCP、ICMP、IP 分片、TCP 四个章节是否都有捕获过程、字段表、协议分析和截图引用。
5. 检查所有关键表格是否包含 Frame Number。
6. 检查 TCP 是否包含三次握手表、释放连接表和消息序列图。
7. 生成 report/final_checklist.md，逐项给出 PASS/WARN/FAIL。
8. 如果我已经提供班级、学号、姓名，请替换报告中的占位符，并生成规范文件名。
9. 如果环境支持 Pandoc，请生成 DOCX；PDF 可由我使用 Word/WPS 导出。若 Pandoc PDF 可用，也可以尝试生成 PDF。
10. 最后输出明确的提交文件路径和仍需人工确认的事项。

输出：
- report/final_checklist.md
- report/计网实验2报告-班级-学号-姓名.docx 或生成说明
- report/计网实验2报告-班级-学号-姓名.pdf 或导出说明
- 提交前人工确认清单

禁止：
- 禁止在个人信息未知时编造班级、学号、姓名。
- 禁止忽略 WARN/FAIL。
- 禁止把包含 TODO 的报告当作最终版。
```
