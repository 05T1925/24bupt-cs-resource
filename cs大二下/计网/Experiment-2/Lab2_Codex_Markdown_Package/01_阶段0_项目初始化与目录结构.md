# 阶段 0：项目初始化与目录结构

> 目标：创建实验项目目录，建立统一文件命名规范，生成 README 和实验元数据模板。  
> 输入：无。  
> 输出：项目目录、README、实验信息模板。

---

## 1. 本阶段要完成什么

本阶段不抓包，只完成实验工作区初始化。Codex 需要创建目录、生成说明文件，并建立后续阶段使用的固定文件名。

## 4. README.md 内容要求

`README.md` 至少包含：

```text
# 计算机网络实验二：IP 和 TCP 数据分组的捕获和解析

## 实验目标
- 捕获并分析 DHCP 报文。
- 捕获并分析 ICMP 报文。
- 捕获并分析 IPv4 数据报分片。
- 捕获并分析 TCP 建立连接和释放连接过程。

## 目录说明
- captures：保存 Wireshark 抓包文件。
- exports：保存 tshark 导出的字段表和分析摘要。
- screenshots：保存实验截图。
- report：保存实验报告草稿、图表和最终文件。
- scripts：保存自动化解析脚本。

## 文件命名规范
- DHCP 抓包：captures/dhcp.pcapng
- ICMP 抓包：captures/icmp.pcapng
- IP 分片抓包：captures/ip_fragment.pcapng
- TCP 抓包：captures/tcp.pcapng
- 报告草稿：report/draft.md
- 最终报告：report/计网实验2报告-班级-学号-姓名.pdf

## 数据真实性要求
所有字段值必须来自真实 pcap 或截图，不允许虚构。
```
