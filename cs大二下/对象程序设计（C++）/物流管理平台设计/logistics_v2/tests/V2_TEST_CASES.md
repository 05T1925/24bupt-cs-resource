# V2 测试用例清单

## 1. 基础身份

- 用户注册成功。
- 重复用户名注册失败。
- 用户密码不含数字或字母时注册失败。
- 管理员新增快递员成功。
- 重复快递员用户名新增失败。
- 冻结快递员后登录失败。
- 删除/停用有未完成任务的快递员失败。

## 2. 多态计费

- 普通快递 `3 kg` 费用为 `15.00`。
- 图书 `4 本` 费用为 `8.00`。
- 易碎品 `2 kg` 费用为 `16.00`。
- 重量为 `0`、负数、三位小数、字母输入均失败。
- 册数为 `0`、负数、小数、字母输入均失败。

## 3. 寄件与资金

- 余额充足时寄件成功，用户余额减少，管理员余额增加。
- 余额不足时寄件失败，快递不新增，余额不变化。
- 收件人不存在时寄件失败。
- 向自己寄件失败。
- 向被冻结用户寄件失败。

## 4. 分配与揽收

- 管理员可给待揽收快递分配快递员。
- 分配给不存在快递员失败。
- 分配给被冻结快递员失败。
- 快递员只能查看自己的待揽收任务。
- 快递员单个揽收成功。
- 快递员批量揽收成功。
- 快递员揽收他人任务失败。
- 重复揽收失败。
- 揽收后状态变为待签收。
- 揽收后管理员余额减少 50%，快递员收入增加 50%。

## 5. 签收

- 收件用户可签收待签收快递。
- 收件用户不能签收待揽收快递。
- 发件用户不能替收件用户签收。
- 无关用户不能签收。
- 已签收快递不能重复签收。
- 批量签收跳过非法序号、重复序号、越界序号。

## 6. 查询权限

- 用户只能查询自己发出或接收的快递。
- 用户按发件人、收件人、时间、单号、状态查询有效。
- 快递员只能查询自己名下任务。
- 快递员按状态查询有效。
- 管理员可查询全部快递。
- 管理员可按快递员查询任务。

## 7. 日志与持久化

- 注册、登录失败、寄件、分配、揽收、签收均写日志。
- 越权查询、越权揽收、越权签收写 `DENIED` 日志。
- 保存失败时业务操作回滚。
- 程序重启后用户、快递员、快递、余额、状态仍保留。
- 如果实现哈希链，手动修改日志后完整性校验失败。
