# V3 验收与加分点设计

## 1. 必做验收对应表

| 实验要求 | V3 落点 |
| --- | --- |
| 网络版功能与单机版一致 | 复用 V2 `LogisticsSystem` 业务能力 |
| 传统 C/S 结构 | `server` 与 `client` 两个独立进程 |
| socket 通信 | Winsock `send/recv` 文本协议 |
| 不能使用 RPC 框架 | 手写 `ProtocolCodec` 和命令路由 |
| 用户登录 | `LOGIN_USER` 返回 token |
| 用户发送快递 | `SEND_EXPRESS`，服务端多态计费 |
| 管理员分配快递员 | `ASSIGN_COURIER` / `AUTO_ASSIGN_COURIER` |
| 快递员揽收 | `PICKUP_EXPRESS` / `PICKUP_BATCH` |
| 用户签收 | `SIGN_EXPRESS` |
| 错误处理 | 协议错误码 + 业务错误码 + 日志 |

## 2. 建议重点展示亮点

### 2.1 真正双进程 C/S

演示方式：

1. 打开一个终端运行 `run_server.bat`。
2. 打开另一个终端运行 `run_client.bat`。
3. 展示 server 正在监听，client 通过 socket 连接。

讲解点：

- client 和 server 是不同进程。
- client 不读写数据文件。
- 所有业务请求都经 socket 到 server。

### 2.2 token 会话安全

演示方式：

- 登录成功后客户端保存 token。
- 手动使用错误 token 请求查询或签收，服务端拒绝。

讲解点：

- 服务端不信任客户端提交的当前用户名。
- 权限身份来自 `SessionManager`。
- 密码和完整 token 不进入日志。

### 2.3 半包/粘包处理

演示方式：

- 在测试程序中连续发送多条命令。
- 或拆成两次发送同一条命令。

讲解点：

- 协议使用 `\n` 作为消息边界。
- socket 流不是消息队列，必须手动分帧。

### 2.4 多客户端并发冲突

演示方式：

- 两个客户端同时尝试签收同一单。
- 或两个客户端同时尝试揽收同一单。

预期：

- 一个成功。
- 另一个返回 `STATE_CONFLICT`。
- server 不崩溃，数据不重复变化。

讲解点：

- 服务端使用互斥锁保护业务核心。
- 状态机在服务端兜底。

### 2.5 继承 V2 加分能力

V3 应继续展示：

- 多态计费。
- 智能自动分配。
- 快递员绩效。
- 管理员统计看板。
- 登录失败三次冻结。
- 原子化保存。
- 日志哈希链。
- 快递员停用冲突清单。

这些功能通过网络客户端触发，更能体现 V3 不是另起炉灶，而是在 V2 业务基础上的架构升级。

## 3. 合理新增加分项

优先级从高到低：

1. 明确的文本协议设计文档。
2. `SessionManager` token 鉴权。
3. 半包/粘包处理。
4. 多客户端并发锁。
5. 网络操作日志。
6. 错误码体系。
7. 客户端断线重连提示。
8. 查询分页。
9. 演示脚本和测试用例。

## 4. 扣分风险

- server 和 client 实际仍是同一个进程。
- 只把菜单拆成两个 exe，但没有 socket。
- client 直接读写 `data/`。
- server 保留 `ConsoleUI` 菜单等待人工输入。
- 使用 HTTP、Web、RPC 框架替代 socket。
- 登录后继续由客户端传 `username` 决定身份。
- 一次 `recv()` 当成完整请求，遇到粘包就错。
- 服务端只靠客户端菜单限制权限。
- 明文密码或完整 token 写入日志。
- 并发下重复揽收、重复签收导致资金重复变化。

## 5. 推荐验收脚本

```text
1. 启动 server，展示监听地址和端口。
2. 启动 admin client，登录管理员。
3. 启动 user client，注册/登录两个普通用户。
4. 用户充值并寄普通、图书、易碎品三类快递。
5. 管理员 client 查询待揽收快递。
6. 管理员手动分配一单，再自动分配一单。
7. 启动 courier client，快递员登录并查看待揽收任务。
8. 快递员揽收，展示状态变为待签收、收入增加。
9. 收件用户 client 查询待签收快递并签收。
10. 管理员查看统计看板和绩效排行。
11. 演示错误 token 被拒绝。
12. 演示两个 client 对同一单重复操作，只成功一次。
13. 演示日志哈希链校验。
14. 简要说明协议分帧、转义、Session 和并发锁。
```
