# 题目二：快递员任务管理系统

## 程序说明

本程序对应综合实验题目二，是独立的单机控制台程序。在题目一基础上增加快递员角色、任务分配、揽收、三状态物流流程和物品继承体系。

`ExpressItem` 为抽象物品基类，`NormalItem`、`FragileItem`、`BookItem` 分别实现普通快递 5 元/kg、易碎品 8 元/kg、图书 2 元/本的 `getPrice()` 多态计价。快递状态按“待揽收 → 待签收 → 已签收”流转，揽收时平台向快递员支付快递费的 50%。

## 编译与运行

环境：Windows、MinGW-w64 g++ 8.1.0 或兼容编译器、C++17。

```bat
build.bat
run.bat
```

源码文件按项目既有 GBK 编码口径编译，构建脚本已设置：

```bat
-finput-charset=GBK -fexec-charset=GBK
```

## 数据文件

- `users.txt`：普通用户。
- `admin.txt`：管理员及平台余额。
- `couriers.txt`：快递员、收入、冻结和停用状态。
- `expresses.txt`：订单、物品类型、数量、费用和三阶段时间。
- `auth_state.txt`：登录失败次数。
- `operations.log`：带哈希链的操作日志。

保存时采用 `.tmp → .bak → 正式文件` 的原子替换策略；提交包仅保留正式数据文件，不包含历史 `.bak`。

## 注意事项

- 密码输入默认以星号隐藏。
- 普通用户、快递员和管理员具有不同权限。
- 快递员只能揽收分配给自己的待揽收任务。
- `bin/` 和可执行文件未随提交包附带，请先编译。
