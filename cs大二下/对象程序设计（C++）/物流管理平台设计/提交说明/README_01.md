# 题目一：物流业务管理与用户管理系统

## 程序说明

本程序对应综合实验题目一，是独立的单机控制台程序。主要实现普通用户注册、登录、修改密码、余额查询与充值、发送快递、签收快递、组合查询，以及管理员查看用户、查询全部快递、冻结/解冻用户和查看操作日志。

快递采用“待签收、已签收”两种状态，每次寄件固定收费 15 元。用户、管理员、快递和操作日志均通过文本文件持久化。

## 目录结构

```text
题目一-物流业务管理与用户管理系统/
├─ src/
│  └─ main.cpp          程序入口及完整类实现
├─ data/
│  ├─ admin.txt         管理员数据
│  ├─ users.txt         普通用户数据
│  ├─ expresses.txt     快递数据
│  └─ operations.log    操作日志
├─ build.bat            编译脚本
├─ run.bat              运行脚本
└─ README.md
```

## 编译与运行

环境：Windows、MinGW-w64 g++ 8.1.0 或兼容编译器、C++17。

```bat
build.bat
run.bat
```

也可在目录中直接编译：

```bat
g++ -std=c++17 -Wall -Wextra -pedantic -O2 -finput-charset=UTF-8 -fexec-charset=GBK src\main.cpp -o bin\logistics_v1.exe
```

## 数据与注意事项

- 程序从项目根目录、`src/` 或 `bin/` 启动时，均会尽量定位到根目录 `data/`。
- 密码使用随机盐与 SHA-256 摘要保存，不以明文写入数据文件。
- 源码按 UTF-8 保存，构建时转换中文字符串到 GBK，以适配 Windows 中文控制台。
- `bin/` 和 `.exe` 属于编译产物，提交包中未预置，运行前请先执行 `build.bat`。
