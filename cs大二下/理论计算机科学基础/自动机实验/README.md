# 上下文无关文法变换 与 下推自动机转文法

理论计算机科学基础实验 —— 上下文无关文法(CFG)与下推自动机(PDA)。

## 运行环境
- Python 3.6+（仅用标准库，无第三方依赖）

## 运行方法
```bash
# 运行内置的两个测试用例（任务一 + 任务二）
python3 main.py

# 对自定义 CFG 文件做化简（任务一）
python3 main.py examples/task1_grammar.cfg
```

## 文件说明
| 文件 | 作用 |
|------|------|
| `grammar.py`   | CFG 数据结构、文本解析、语言枚举、变量重命名 |
| `transforms.py`| 消除 ε 产生式 / 单产生式 / 无用符号，及规范化简 `simplify` |
| `pda.py`       | PDA 数据结构、文本解析、由 PDA 构造等价 CFG |
| `main.py`      | 主程序，演示两个任务的完整流程并自带正确性验证 |
| `examples/task1_grammar.cfg` | 任务一测试文法 |
| `examples/task2_pda.txt`     | 任务二测试下推自动机 |

## 输入格式

### CFG（`.cfg`）
- 每行一条产生式：`左部 -> 右部1 | 右部2 | ...`（`->` 或 `→` 均可）。
- 大写字母为变量(非终结符)，其余字符为终结符；`ε`/`eps`/`$`/空 表示空串。
- 第一条产生式的左部即起始符号；`#` 开头为注释。

### PDA（`.txt`）
```
states: q0 q1            # 状态集
input:  a b             # 输入字母表
stack:  B z0            # 栈字母表
start_state: q0         # 初始状态
start_stack: z0         # 初始栈符号
final:                  # 终态集（留空 => 以空栈接受）
transitions:
q0,b,z0 -> q0,Bz0       # δ(q0,b,z0)={(q0,Bz0)}
q0,a,B  -> q1,          # 压栈串为空表示弹栈
q1,,B   -> q1,          # 输入符号为空(两逗号相邻)表示 ε 转移
```

## 输出格式
按「步骤」依次打印每个变换的中间集合（可空变量、单元对、产生/可达符号等）
与对应文法，最后给出化简后的文法，并用「枚举有限长度内语言」的方式自动验证
化简前后语言一致（任务一）/ 与 PDA 接受的语言一致（任务二）。
