## 第 1 题：Watchdog

运行：

```powershell
java -cp target\classes WatchdogDemo
```

验收观察：第一代 A 线程发送 5 次心跳后模拟故障；B 线程连续 10 次未检测到
心跳后报警，安全结束旧线程并创建第二代 A 线程；第二代恢复 3 次心跳后程序结束。

可能提问：

- 为什么使用 `AtomicInteger`？保证线程间可见性，并让读取后清零成为原子操作。
- 为什么不能重新 `start()` 原 Thread？一个 Thread 对象只能启动一次，重启必须新建对象。
- 为什么不用 `Thread.stop()`？它可能在共享数据修改到一半时强制终止线程。

## 第 2 题：10 线程求和

运行：

```powershell
java -cp target\classes SumThreadDemo
```

验收观察：10 个局部区间都会输出，线程输出顺序可能变化，最终结果固定为 `5050`。

可能提问：

- `start()` 和 `run()` 有什么区别？`start()` 创建新线程，直接调用 `run()` 仍在当前线程执行。
- 为什么使用 `join()`？主线程必须等所有子线程完成后才能输出最终结果。
- 为什么先算局部和？减少多个线程频繁修改共享变量的次数。

## 第 3 题：仓库存取

运行：

```powershell
java -cp target\classes WarehouseDemo
```

建议依次输入：

```text
1 3
3 5
2 2
q
```

第一条取货会因库存不足进入等待；存货成功后通过 `notifyAll()` 唤醒取货线程。

可能提问：

- 为什么三个仓库使用同一把锁？存取需要比较三个仓库的整体库存状态。
- 为什么 `wait()` 放在 `while` 中？线程可能虚假唤醒，醒来后必须重新检查条件。
- 为什么用 `notifyAll()`？库存变化可能让不同等待线程满足条件，不能只随机唤醒一个。

## 第 4 题：目录复制

准备测试目录：

```powershell
New-Item -ItemType Directory -Force "xcopy_demo\dir1\sub"
New-Item -ItemType Directory -Force "xcopy_demo\dir1\empty"
Set-Content -Encoding UTF8 "xcopy_demo\dir1\a.txt" "根目录文件"
Set-Content -Encoding UTF8 "xcopy_demo\dir1\sub\b.txt" "子目录文件"
```

运行与检查：

```powershell
java -cp target\classes XCopy "xcopy_demo\dir1" "xcopy_demo\dir2"
tree "xcopy_demo\dir2" /F
```

验收重点：目标目录原本可以不存在；文件、子目录和空目录都被复制。

可能提问：

- `walkFileTree()` 做什么？递归遍历整棵目录树。
- `preVisitDirectory()` 为什么创建目录？进入目录时先创建对应目标目录，因此空目录也能保留。
- `relativize()` 和 `resolve()` 做什么？先求源内相对路径，再拼到目标目录以保持层级。

启动 Tomcat：

```powershell

```

可能提问：

- JSP 代码在哪里执行？由 Tomcat 在服务器端执行并生成 HTML。

- 天气查询为什么先查经纬度？预报接口需要经纬度，城市名先通过地理编码接口转换。
- Gson 做什么？把接口返回的 JSON 解析为 Java 可读取的数据。

## 第 6 题：Swing 按钮界面

运行：

```powershell
java -cp target\classes ButtonGridDemo
```

依次验收：点击 5 看按钮 6；点击 7 看按钮 8；连续点击 9 看按钮 10；
点击 10 和 11 看按钮 15 的颜色。

可能提问：

- 为什么使用 `GridBagLayout`？它支持跨行、跨列和按权重缩放，适合不规则布局。
- `gridwidth` 是什么？组件横向跨越的网格数量。
- 为什么 Swing 放在 EDT 中创建？Swing 不是线程安全的，界面操作应在事件派发线程执行。
- 10 和 11 如何共用监听器？给两个按钮注册同一个 `ActionListener`，通过事件源区分。

## 第 7 题：泛型组合排序

运行：

```powershell
java -cp target\classes CoupleSortDemo
```

验收重点：排序顺序符合比较器规则，且学生和原成绩始终保持配对。

可能提问：

- 为什么两个数组必须同时交换？同一下标的 A、B 对象共同构成一个组合。
- 泛型的作用是什么？排序方法不依赖具体的 `Student`、`Score` 类型。
- 比较器返回值含义是什么？负数表示第一个组合应排前，0 表示相等，正数表示排后。
- 当前算法是什么？选择排序，每轮找到应放在当前位置的组合，时间复杂度为 O(n²)。
