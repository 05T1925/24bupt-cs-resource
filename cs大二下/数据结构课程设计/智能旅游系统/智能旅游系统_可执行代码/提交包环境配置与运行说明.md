# 智能旅游系统环境配置与运行说明

## 1. 项目组成

本系统由以下部分组成：

- React + Vite 前端，端口 `5173`；
- Spring Boot Java 后端，端口 `8080`；
- Python FastAPI Agent，端口 `9000`；
- MySQL业务数据库，端口 `3306`；
- Redis缓存服务，端口 `6379`；
- SQLite Agent本地会话与任务数据；
- `uploads`本地图片和媒体资源。

## 2. 基础环境

建议在Windows环境运行，并安装：

1. JDK 17或兼容版本；
2. Maven 3.9或兼容版本；
3. Node.js及npm；
4. Python 3.10或更高版本；
5. MySQL 8；
6. Redis；
7. Chrome、Edge等现代浏览器。

可使用以下命令检查：

```powershell
java -version
mvn -version
node -v
npm -v
python --version
```

## 3. MySQL配置

启动MySQL后创建数据库：

```sql
CREATE DATABASE tourism_db
  DEFAULT CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;
```

后端启动时会通过Flyway执行迁移。项目还提供`sql`目录中的基础表、种子和周边数据脚本；是否导入扩展数据应根据实际数据库状态决定，避免重复导入。

在启动后端前设置数据库环境变量：

```powershell
$env:TOURISM_DB_URL="jdbc:mysql://localhost:3306/tourism_db?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true"
$env:TOURISM_DB_USERNAME="root"
$env:TOURISM_DB_PASSWORD="请填写本机MySQL密码"
$env:TOURISM_JWT_SECRET="请填写不少于32字符的随机密钥"
```

## 4. Redis配置

启动Redis并检查：

```powershell
redis-cli ping
```

返回`PONG`表示连接正常。Redis主要用于小红书缓存和限流，不是地点、日记等全部核心查询的必要条件。

## 5. 安装项目依赖

### 5.1 Java后端

在项目根目录执行：

```powershell
mvn dependency:resolve
```

### 5.2 React前端

```powershell
cd frontend
npm ci
cd ..
```

### 5.3 Python Agent

```powershell
cd agent-service
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -e ".[test]"
Copy-Item .env.example .env
cd ..
```

编辑`agent-service\.env`，按需设置文本模型、视觉模型和小红书配置。密钥和Cookie不得提交到公共仓库。

## 6. AI与外部服务配置

文本模型可通过以下变量配置：

```text
TEXT_LLM_MODEL=deepseek-chat
TEXT_LLM_BASE_URL=https://api.deepseek.com
TEXT_LLM_API_KEY=填写文本模型Key
```

图片理解需要独立视觉模型：

```text
VISION_LLM_MODEL=qwen-vl-max
VISION_LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
VISION_LLM_API_KEY=填写视觉模型Key
```

DeepSeek主要承担文本理解和生成，不承担图片理解。小红书热门或同步能力需要有效Cookie、账号状态、网络和外部平台可访问；未配置时应使用降级展示。

## 7. 启动系统

确保MySQL和Redis已经启动，然后在项目根目录执行：

```powershell
.\run\start-apps.ps1
```

也可分别启动：

```powershell
# 后端
mvn spring-boot:run

# 前端（新终端）
cd frontend
npm run dev

# Agent（新终端）
cd agent-service
.\.venv\Scripts\Activate.ps1
python -m uvicorn app.main:app --host 0.0.0.0 --port 9000
```

停止应用：

```powershell
.\run\stop-all.ps1
```

## 9. 构建与测试

```powershell

# Agent测试
cd ..\agent-service
.\.venv\Scripts\Activate.ps1

```

最新验收口径为：三端健康检查返回200，前端生产构建成功，MySQL数据及Flyway迁移成功，Redis返回PONG；Java测试126/132通过，XHS测试29/33通过，前端lint仍有8个错误、4个警告。剩余失败属于代码或旧测试契约问题，并非环境缺失。

## 10. 运行边界

- 路线规划依赖地点坐标和`spot_road_edge`路网覆盖；
- 周边数据含真实POI、脚本数据和批量数据，质量需分层说明；
- 多模态依赖视觉模型Key、网络和图片可访问性；
- 小红书依赖Cookie、外部平台、账号和缓存；
- SQLite只用于Agent本地状态，不是业务主数据库；
- `uploads`包含展示媒体，应保留目录结构；
- 不要将`.env`、真实密钥、Cookie、数据库密码或本机`.local`目录提交。
